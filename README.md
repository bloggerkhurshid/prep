# PREP BY KHURSHID

A distraction-free, ultra-clean black & white technical and HR interview prep web application built with **React**, **Vite**, and **Tailwind CSS**.

![PREP BY KHURSHID Preview](https://img.shields.io/badge/Status-Active-brightgreen) ![License](https://img.shields.io/badge/License-MIT-blue)

---

## 🌟 Key Features

- ⚡ **Minimalist Black & White Design**: Focused, distraction-free interface for studying interview questions without visual noise.
- 🌓 **Dark / Light Mode Toggle**: Seamless one-click dark mode switcher for comfortable night reading.
- 📚 **Comprehensive Technical & Non-Technical Coverage**:
  - **HTML & CSS**: Core concepts, Box Model, Flexbox/Grid, Pseudo-elements, Media Queries, DOCTYPE, and Semantic tags.
  - **Bootstrap**: Breakpoints, Grid system, Containers, and Responsive utilities.
  - **JavaScript**: Hoisting, Closures, Event Loop, Promises, Async/Await, Debouncing/Throttling, ES6+ features, and Scopes.
  - **React JS**: Virtual DOM, Diffing algorithm, Hooks, Context API, Redux workflow, Controlled vs Uncontrolled components, and Performance optimizations (`React.memo`, `useMemo`, `useCallback`).
  - **HR & Intro**: Self-introduction pitch, Strengths & Weaknesses, 3-5 Year goals, and handling high-pressure scenarios.
- 🎯 **Click-to-Expand Q&A Stream**: Interactive card expansion revealing structured, bolded explanations and code snippets.
- 🔍 **Real-time Search & Category Filtering**: Instant search across questions, topics, and answers with responsive category pills.
- 📐 **Max 7XL Desktop Layout**: Clean 100% responsive layout constrained to `max-w-7xl` on desktop.
- 💯 **100/100 SEO & Accessibility Optimized**: Semantic HTML5 headers (`<h1>`), full Open Graph meta tags, preconnected fonts, and WCAG compliant `aria-label` controls.

---

## 🛠️ Technology Stack

- **Framework**: React 18 (Vite)
- **Styling**: Tailwind CSS (Custom Dark Mode & Literata Serif Typography)
- **Icons**: Lucide React
- **Data Architecture**: Processed JSON dataset from structured docx technical documents

## 🚀 Getting Started

### Prerequisites
Make sure you have **Node.js** (v16+) installed.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/bloggerkhurshid/prep.git
   cd prep
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
